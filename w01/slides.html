정의 · 교과서 79쪽

확률변수의 정의

표본공간의 각 원소에 실수 하나를 대응시키는 함수 = 확률변수

X : S → 실수 전체

이름은 변수, 실제는 함수

정의역: 표본공간 S · 공역: 실수 전체

기호

확률변수 X, Y, Z · 그 값 x, y, z

P(X = x)

확률변수 X가 값 x를 가질 확률

공학 예

부품 10개 검사 → X = 불량품 개수 (0~10)

대문자는 함수(규칙), 소문자는 그 함수가 내놓은 값이라는 구분 강조.

플립북: 이산과 연속

이산확률변수 = 낱장

값이 유한개이거나
자연수처럼 하나, 둘, … 셀 수 있음

연속확률변수 = 움직임

어떤 범위 안의 모든 실수 값
값과 값 사이에 빈틈 없음

그림: John Barnes Linnet, The Kineograph (1886), 퍼블릭 도메인

플립북 한 장 한 장은 끊어진 그림이지만 빠르게 넘기면 연속 동작으로 보임. 이산 = 낱장, 연속 = 움직임.

확률질량함수 · 교과서 81쪽

이산확률변수의 확률분포

값 xᵢ에 확률 pᵢ를 대응시키는 함수

P(X = xᵢ) = pᵢ (i = 1, 2, …, n)

대응 관계 = 확률분포 · 예: 동전 두 번, 앞면 횟수 X

X012합계
P(X = x)1/41/21/41

질량 = 각 값 위에 얹힌 확률의 무게

확률분포 = 값과 확률의 대응 관계. 표와 그래프 두 가지로 표현.

확률질량함수 · 교과서 82쪽

확률질량함수의 성질

비유: 확률 1리터를 여러 컵에 나눠 담기

컵 하나는 0 이상 1 이하 · 모든 컵의 합 = 1 · 구간의 확률 = 그 구간 컵들의 합

전체 확률 1을 여러 컵에 나눠 담는 비유. 각 컵은 0~1, 모두 합치면 1, 구간 확률은 해당 컵의 합.

예제 · 교과서 82쪽 예제 2를 공학 상황으로 변형

부품 표본검사의 불량품 개수

부품 7개 중 불량품 3개

임의로 3개 꺼내 검사

X = 꺼낸 불량품 개수

P(X ≥ 2) = 12/35 + 1/35 = 13/35

→ 3개 중 2개 이상이 불량일 확률 약 37%

사진: Encik Tekateki, Quality Control of Ceramic Mugs, CC BY-SA 4.0, Wikimedia Commons

7개 중 3개를 뽑는 경우의 수 ₇C₃ = 35. P(X ≥ 2) = 12/35 + 1/35 = 13/35. 비복원추출(초기하분포)이라는 이름은 나중에 소개.

연속확률변수 · 교과서 83쪽

연속은 왜 다를까?
회전 원판

0~10 눈금 원판, 바늘이 멈춘 눈금 X

질문: 바늘이 정확히 3.000…에 멈출 확률은?

가능한 값이 무수히 많음 → 한 점의 확률 = 0

구간으로 물음: P(a ≤ X ≤ b) = (b − a) / 10

그림: Douglas Perkins, Basic roulette wheel, CC0, Wikimedia Commons

바늘이 정확히 3.000…에 멈출 확률은? → 0. 그래서 연속은 한 점이 아니라 구간으로 확률을 물음. 다음 장에서 실제로 400번 돌려 봄.

실시간 시뮬레이션 · 교과서 83쪽

원판을 400번 돌리면

처음 5번은 천천히, 이후 400번까지 빠르게 · 멈춘 눈금이 고르게 쌓임 → f(x) = 1/10 · 넓이 = 확률

실시간 시뮬레이션(매번 다른 결과). 처음 5번은 천천히 돌며 바늘이 멈추는 모습, 이후 400번까지 빠르게 쌓임. 막대가 평평해지면 3~7 구간이 주황으로 칠해지며 실제 비율과 이론값 0.4 비교. 약 9초 후 처음부터 다시 시작.

확률밀도함수 · 교과서 83·85쪽

연속확률변수의 확률분포

밀도 = 확률이 얼마나 빽빽한지

f(x) 자체는 확률이 아님
넓이(정적분)가 확률
f(x) > 1인 경우도 가능

한 점의 확률 = 0

α ≤ x ≤ β에서 정의된 f(x). 성질 2: 전체 넓이 1, 성질 3: 구간 확률 = 넓이 = 정적분. 한 점의 확률이 0이므로 등호 유무와 상관없이 같은 확률.

애니메이션 · 교과서 85쪽 탐구

막대에서 곡선으로

계산 대기 시간 f(x) = x(12 − x)/288 · 막대 넓이의 합(이산) → 곡선 아래 넓이(연속)

영상 클릭 시 재생(약 17초). 막대 폭이 0으로 가는 극한 = 확률밀도함수. 플립북 비유와 연결. 마지막 장면: P(0 ≤ X ≤ 3) = 5/32.

실시간 탐색기 · 교과서 85쪽

구간이 바뀌면 넓이도 바뀜

구간 [a, b]가 자동으로 바뀌며 넓이 P(a ≤ X ≤ b) = ∫ f(x) dx 값을 실시간 계산 · 4초마다 다음 구간

자동으로 구간이 바뀌는 탐색기. 학생에게 다음 구간의 확률을 먼저 예측하게 한 뒤 값 확인. 0~12 전체는 1, 0~6은 대칭이라 0.5. 2~4와 4.5~7.5처럼 폭이 비슷해도 가운데가 더 큼 → 밀도의 의미.

예제 · 교과서 84쪽 예제 3

확률밀도함수 f(x) = kx (0 ≤ x ≤ 3)

⑴ 상수 k의 값

넓이로 보면: 삼각형 ½ × 3 × 3k = 1

⑵ P(2 ≤ X ≤ 3)

넓이로 보면: 사다리꼴 ½ × (4/9 + 6/9) × 1

넓이로 풀어도 되고(삼각형, 사다리꼴) 정적분으로 풀어도 됨. 두 방법 모두 보여주기.
